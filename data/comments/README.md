# comments

Сюда сохраняются комментарии ревьюеров.

Каждый комментарий — отдельный `.yaml` файл в JSON-совместимом формате YAML.

Поддерживаются два типа цели:

- комментарий к конкретной задаче:
  - `target.type = "problem"`
  - `target.problem_id = "..."`
- общий комментарий по архитектуре базы:
  - `target.type = "architecture"`

Viewer умеет показывать существующие комментарии и генерировать новые файлы комментариев для сохранения в эту папку.
