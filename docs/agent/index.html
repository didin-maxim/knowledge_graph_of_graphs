Graph DB Agent Access

Lightweight entry point for remote browser agents. This layer is generated from data/; source-of-truth records remain the raw YAML files. The human viewer is still ../index.html.

catalog.jsonCounts, entry points, and source chunks. problems-compact.jsonlSmall all-problem manifest for first-pass search. problems.jsonlAll problem cards, one JSON object per line. problems.mdPlain Markdown catalog for quick browsing. README.mdRules for using the database as an information source. topics/game-strategy.htmlBrowser-readable dump of graph game and strategy tasks. topics/game-strategy.jsonlCurated graph game and strategy tasks. topics/game-strategy-candidates.jsonlWider text/profile matches for missing-tag audits.

Rules

  1. Use this directory for discovery; cite the problem id and path.
  2. Source of truth: open a record's raw_github_url for the authoritative YAML card.
  3. Do not treat GitHub code search or viewer load failures as evidence that a task is absent.
  4. Start with problems-compact.jsonl; use source chunks when full files are too large for the browser tool.
  5. For graph games and strategy tasks, use topics/game-strategy.html for browser reading or topics/game-strategy.jsonl for structured data. Use the candidates file only for an audit, not as the final answer.
