# yumt-2014-start-final-problem1

## Краткий итог

Карточка была без решения. Точный внешний разбор задачи ЮМТ 2014, Старт-лига, финал, задача 1 по формулировке про 111 городов и закрытие дорог любого кольцевого маршрута не найден.

Добавлено ИИ-решение: ответ \(220\). Верхняя оценка элементарная: если в связном мультиграфе на \(n\) вершинах хотя бы \(2n-1\) рёбер, то после удаления рёбер произвольного остовного дерева остаётся не меньше \(n\) рёбер, значит, среди них есть цикл; удаление рёбер этого цикла не разрушает оставшееся остовное дерево. Для \(n=111\) это запрещает \(221\) и более рёбер. Равенство \(220\) достигается удвоенной звездой.

## Внешняя теорема

Внешняя теорема не нужна. Используется только школьный факт: лес на \(n\) вершинах имеет не больше \(n-1\) рёбер, а связный граф содержит остовное дерево. Отдельную карточку-теорему добавлять не требуется.
