# miklos-schweitzer-2004-p2-quasirandom-k4-count

## Краткий итог

Карточка была без решения. Готовый публичный разбор именно задачи Miklos Schweitzer 2004/2 не найден; найден и сверлен только официальный английский PDF с условием.

Добавлено ИИ-решение: из контроля величин \(e_{G_1}(S)-e_{G_2}(S)\) для всех \(S\subseteq V\) выводится cut-нормовая оценка для разности матриц смежности, затем телескопируется счёт упорядоченных копий \(K_4\). Константы сходятся точно: переход к cut-норме даёт множитель \(4\), телескопирование по шести рёбрам даёт множитель \(6\), а переход от упорядоченных копий к неупорядоченным делит на \(24\).

## Внешние теоремы

Внешняя теорема не использована. В решении прямо доказаны две стандартные леммы, которые обычно формулируются как часть counting lemma для cut-нормы:

- из контроля \(q(S)\) для всех множеств \(S\) следует \(|\sum_{x\in X,y\in Y}D(x,y)|\le4\varepsilon n^2\) для любых \(X,Y\);
- такая cut-нормовая оценка контролирует один телескопический член счёта \(K_4\).

Оценка школьности: доказательство не требует тяжёлой теории, но язык матриц смежности, cut-нормы, layer-cake представления и телескопирования произведения скорее олимпиадно-университетский. Отдельную карточку-теорему можно добавить как полезную общую лемму `cut-norm-counting-lemma-k4`, но для этой карточки это не обязательно, потому что доказательство полностью включено.
