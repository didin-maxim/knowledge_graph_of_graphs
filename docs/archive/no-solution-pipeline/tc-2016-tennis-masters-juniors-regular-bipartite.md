# tc-2016-tennis-masters-juniors-regular-bipartite

## Краткий итог

Карточка была без решения. Решение найдено в публичной копии PDF с решениями устного тура 37-го Турнира городов и затем переписано как самодостаточное ИИ-решение.

Добавлено решение через таблицу \(30\times30\): пары мастеров задают пары столбцов, пары юниоров задают пары строк, а межгрупповые партии закрашивают клетки. Если нужного блока \(2\times2\) нет, каждый блок обязан быть ровно одной горизонтальной или вертикальной доминошкой. Равенство сумм в парных столбцах даёт чётность числа вертикальных доминошек, равенство сумм в парных строках даёт чётность числа горизонтальных доминошек, но всего блоков \(15^2=225\), что нечётно.

## Найденные источники

- Уже существующий source_id `src-tc-2016-37-oral-official`: официальный PDF `https://www.turgor.ru/problems/37/vs-37-ustn-avt.pdf`; локальный извлечённый текст подтверждает полную формулировку и автора Александра Грибалко.
- Публикация условия в журнале «Квант»: `https://kvant.mccme.ru/pdf/2016/2016-03.pdf`.
- Публичная копия PDF с решениями: `https://ru.scribd.com/document/856286467/vs-37-ustn-sol`. В ней есть два решения задачи 4; в карточку внесена переформулированная версия первого решения.

## Внешние теоремы

Внешние теоремы не использовались. Доказательство школьное: нужны только таблица, подсчёт степеней и чётность. Отдельную карточку-теорему добавлять не требуется.
