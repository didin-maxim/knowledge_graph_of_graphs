## Содержание решения

Ключевая идея: удалить все мосты. Каждая нетривиальная компонента без мостов наследует условие задачи. В такой компоненте все степени не меньше 2; если у вершины есть три инцидентных ребра `e,f,g`, то после удаления `e` граф остаётся связным, а `f` и `g` должны стать мостами. Но два разных моста из одной вершины отделяют непересекающиеся части, и одно добавляемое ребро `e` не может одновременно возвращать связность через обе части. Значит, все степени равны 2, то есть компонента является циклом.

Если циклических компонент `c`, то число рёбер равно `n - 1 + c`: мосты образуют дерево между компонентами, а каждая циклическая компонента даёт одно лишнее ребро сверх дерева. Так как каждая циклическая компонента содержит не менее 3 вершин, `c <= floor(n/3)`.

Оценка достигается: взять `floor(n/3)` непересекающихся треугольников, оставшиеся вершины одиночными, выбрать по одной вершине в каждом объекте и соединить только выбранные вершины мостами в дерево.

## Внешняя теорема

Внешняя теорема не нужна. Используются только определения связности, моста, цикла и элементарный факт: связный конечный граф, все вершины которого имеют степень 2, является циклом.
