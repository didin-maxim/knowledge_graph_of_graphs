# yumt-2024-grand-final-problem9

Карточка была без решения. В открытом поиске точный публичный разбор и автор задачи не найдены; найденные страницы ЮМШ/ЮМТ подтверждают наличие официальных архивов условий/решений по годам, но поиск по тексту этой задачи не дал отдельного решения.

Добавлено самостоятельное ИИ-решение `sol-ai-diagonal-pair-orientation`. Идея: у каждого 4-цикла берутся две пары противоположных вершин; эти пары становятся вершинами вспомогательного графа, а каждая исходная вершина становится ребром между двумя такими парами для двух циклов, проходящих через неё. Получается 2-регулярный мультиграф, его компоненты ориентируются по кругу. В каждом исходном 4-цикле ориентация выбирает по одной вершине из каждой противоположной пары, то есть две соседние вершины; ребро между ними и выбирается.

## Внешний поиск

- Искались точные фразы условия: "Рёбра графа разбиваются на циклы длины 4", "все вершины имеют степень 4", "из каждого из этих циклов длины 4 можно выбрать по ребру".
- Проверялись запросы по ЮМТ/ЮМШ 2024, Grand Final/Гранд-лига и ключевым словам "паросочетание", "4-циклы".
- Официальная страница архива ЮМШ 2023/24 указывает на PDF "Олимпиада 23-24" с условиями и решениями всех туров, но поиск внутри найденного PDF по этой формулировке не нашёл задачу; возможно, карточка относится к другому архивному файлу ЮМТ или формулировка была нормализована при импорте.

## Внешние теоремы

Внешние теоремы не использованы. Единственный факт: конечный 2-регулярный мультиграф является объединением циклов и его компоненты можно ориентировать по кругу. Это элементарный шаг, доказуемый прямо из степени 2, отдельная карточка-теорема не требуется.
