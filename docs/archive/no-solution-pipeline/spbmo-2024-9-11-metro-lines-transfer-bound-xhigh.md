## Математический статус

Решение в карточке самостоятельное. Ключевые шаги:

- Свести связный граф к остовному дереву; дополнительные рёбра можно сделать однотоннельными линиями и не использовать в маршрутах.
- В дереве разбиение на линии эквивалентно локальному выбору пар инцидентных рёбер в вершинах; пересадка на маршруте происходит в вершине, где две стороны маршрута не склеены в одну линию.
- Ввести ранг ориентированной ветви: `0` для листовой ветви и `max(a1, a2 + 1)` по двум наибольшим рангам следующих ветвей.
- Использовать лемму, что ветвь ранга `s` содержит минимум `2^(s+1)-1` вершин, а максимальное число пересадок в дереве задаётся локальными вкладами вершин через ранги выходящих ветвей.
- Верхняя оценка: дерево с не более чем `3*2^51 - 3` вершинами не может иметь локальный вклад `101`.
- Нижняя оценка: центральная вершина с тремя минимальными ветвями ранга `50` имеет `3*2^51 - 2` вершины и вынуждает `101` пересадку между двумя подходящими листьями.

Для sanity-check рангового критерия были перебраны малые деревья через `networkx.nonisomorphic_trees`; первые пороги для минимально вынужденных пересадок совпали с ранговой формулой: `4, 6, 10, 14` вершин для `1, 2, 3, 4` пересадок соответственно.
