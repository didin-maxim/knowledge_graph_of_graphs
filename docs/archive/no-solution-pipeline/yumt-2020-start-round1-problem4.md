## Итог по решению

Добавлено ИИ-решение `sol-ai-unbounded-by-isolated-vertices` со статусом `ai_checked`.

Буквальная формулировка не имеет конечного максимума. Для любого \(N\ge 2\) достаточно взять граф на \(N\) вершинах с ровно одним ребром и \(N-2\) изолированными вершинами. Степени не превосходят \(1\), а четвёрки с двумя рёбрами \(AB\) и \(CD\) вообще не существует, поэтому условие выполняется вакуозно.

В `review_notes` решения добавлена осторожная оговорка: если в исходном PDF подразумевалась связность или отсутствие изолированных вершин, нужна отдельная сверка формулировки. По текущему тексту карточки решение полное.
