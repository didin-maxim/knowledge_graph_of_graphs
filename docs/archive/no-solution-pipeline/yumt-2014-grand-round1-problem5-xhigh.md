## Математическая сверка

Ключевой пересчёт для ЮМТ: если все циклы имеют разные длины, циклов всего не больше `3n-2`. После выбора остовного леса с `3n-c` рёбрами остаётся `q=2n+c >= 2n+1` дополнительных рёбер. Их фундаментальные циклы имеют разные длины, поэтому сумма длин древесных частей не меньше `2+3+...+(q+1)`.

Отсюда некоторое ребро леса лежит в `k > (2n+5)/3` фундаментальных циклах. Любая пара таких циклов даёт новый простой цикл, содержащий оба соответствующих дополнительных ребра; разные пары дают разные циклы. Тогда циклов больше

`2n+1 + ((2n+5)/3)((2n+2)/3)/2 = (2n^2+25n+14)/9 > 3n-2`,

что противоречит попарной различности длин. Случай `n=1` невозможен для простого графа, так как на трёх вершинах не может быть пяти рёбер.
