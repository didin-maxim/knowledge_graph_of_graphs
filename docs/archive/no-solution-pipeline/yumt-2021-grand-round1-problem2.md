# yumt-2021-grand-round1-problem2

## Краткий итог

Карточка была без решения. Автор и опубликованный официальный разбор по точной формулировке в открытом поиске не найдены.

Добавлено ИИ-решение: задача сводится к теореме Зыкова о том, что среди графов на `n` вершинах без `K_{k+1}` число `r`-клик каждого фиксированного размера максимально у графа Турана `T(n,k)`. В `T(n,k)` число всех клик равно `prod (a_i+1)`, где `a_i` - размеры долей; для целых `a_i+1 >= 2` применяется оценка `a_i+1 <= 3^((a_i+1)/3)`.

## Внешняя теорема

Использована теорема Зыкова: для любых `n`, `k` и `r` граф Турана `T(n,k)` максимизирует число `r`-клик среди всех `n`-вершинных графов без клики размера `k+1`.

Оценка школьности: теорема нетривиальна, но стандартна в экстремальной теории графов и доказывается симметризацией Зыкова, близкой к классическому доказательству теоремы Турана. Для олимпиадной карточки Гранд-лиги это допустимый внешний факт только если он уже известен участникам; иначе лучше добавить отдельную карточку-лемму с доказательством симметризацией.
