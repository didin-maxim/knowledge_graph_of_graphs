## Решение

Использована стандартная идея минимального контрпримера. Если граф не 3-раскрашиваем, берём минимальный не 3-раскрашиваемый подграф `H`. Тогда для любого ребра `e=xy` граф `H-e` уже 3-раскрашиваем, причём концы `x,y` имеют один цвет.

Для четырёх циклических порядков цветов `(1,2)`, `(1,3)`, `(1,2,3)`, `(1,3,2)` строится ориентированный граф переходов по цветам. Если из `x` нет пути в `y`, то достижимую из `x` область можно циклически перекрасить, после чего ребро `xy` возвращается без конфликта. Значит для каждого порядка есть путь `x-y`; вместе с `xy` это даёт четыре различных цикла через одно ребро. Это противоречит условию, что каждое ребро принадлежит не более чем трём циклам.

## Внешние теоремы

В решении не используется внешняя теорема: нужная Kempe-chain лемма доказана прямо в карточке. Родственный современный результат - Moore, West, "Cycles in Color-Critical Graphs", Electronic Journal of Combinatorics 28(4), 2021, `https://doi.org/10.37236/10177`; он значительно сильнее, чем нужно для этой задачи, поэтому как зависимость карточки не требуется.
