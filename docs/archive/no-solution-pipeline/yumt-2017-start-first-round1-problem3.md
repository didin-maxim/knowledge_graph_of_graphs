# yumt-2017-start-first-round1-problem3

## Краткий итог

Карточка была без решения. Готовый публичный/официальный разбор и автор именно этой задачи в быстром открытом поиске не найдены.

Добавлено ИИ-решение: ответ \( \binom n2-1 \). Верхняя оценка элементарна: при \(k=\binom n2\) граф полный, поэтому любые выбранные Петей \(A\) и \(B\) соединены ребром, и Вася выигрывает первым ходом. Оценка достигается полным графом без ребра \(AB\): Петя выбирает концы отсутствующего ребра и после каждого хода Васи удаляет ребро из текущего города фишки в \(B\), если оно есть.
