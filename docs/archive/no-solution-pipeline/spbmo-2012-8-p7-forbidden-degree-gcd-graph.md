## Математическая попытка

Для существующей СПбМО-2012-8-P7 задачи естественная модель такая: есть простой 40-регулярный граф `G` на 100 вершинах, любые две вершины имеют не более 20 общих соседей; нужно найти 22 вершины, образующие чередующийся цикл знакомств и незнакомств в полном графе.

Быстрый перспективный ход:

- взять большое паросочетание из рёбер `G`;
- для двух рёбер паросочетания считать их "совместимыми", если между ними есть хотя бы одна пара незнакомых концов;
- ограничение на общих соседей даёт, что фиксированное ребро может быть "плохо" не более чем с 10 рёбрами паросочетания, потому что оба конца плохого ребра должны быть общими соседями концов фиксированного ребра;
- максимальное паросочетание в 40-регулярном графе имеет размер хотя бы 25: иначе слишком много непокрытых вершин, каждая степени 40, должны иметь все свои рёбра в слишком малое множество покрытых вершин;
- получается вспомогательный граф на 25 рёбрах паросочетания с минимальной степенью хотя бы 14.

Дальше нужен надёжный шаг: из такого вспомогательного графа получить цикл длины 11, а затем ориентировать соответствующие 11 рёбер паросочетания так, чтобы получить рассадку 22 человек с чередованием знаком/незнаком. Это верно следует из стандартных пэнциклических результатов типа теоремы Бонди для графов с достаточно большой минимальной степенью, но это уже внешняя теорема и не выглядит подходящим школьным доказательством для карточки 8 класса без отдельного развёрнутого доказательства.

Поэтому полноценное решение в карточку не добавлено.

## Внешние теоремы

Потенциально применимая внешняя теорема: если граф на `n` вершинах имеет минимальную степень больше `n/2`, то он содержит циклы всех длин от 3 до `n` (пэнцикличность; близко к теореме Бонди/следствиям из теоремы Дирака).

Оценка школьности: в таком виде теорема не школьная для 8 класса. Её можно использовать в базе только как отдельную карточку-лемму с доказательством или заменить на специальную элементарную лемму "граф на 25 вершинах с минимальной степенью 14 содержит 11-цикл".
