# yumt-2017-premier-round1-problem2

Карточка была без решения. Публичный официальный файл с условием найден: `https://adygmath.ru/content/files/smena2017/umt/zadaniya/zadan_1tur_prem.pdf`, страница 1, задача 2. Готовый опубликованный разбор и автор задачи быстрым открытым поиском по точным фрагментам условия не найдены.

Добавлено полноценное самодостаточное ИИ-решение. Ответ:
\[
\binom{n-1}{2}=\frac{(n-1)(n-2)}2.
\]

Идея решения:

- Верхняя оценка: если перед первым ходом Васи расстояние от `A` до `B` не больше 2, Вася сразу попадает в `B`. Значит, в выигрышной позиции Пети у `A` и `B` нет ребра и нет общего соседа. Тогда каждый из остальных `n-2` городов смежен не более чем с одним из `A,B`, а между остальными городами максимум `C(n-2,2)` дорог. Итого `k <= C(n-2,2)+(n-2)=C(n-1,2)`.
- Конструкция: на всех городах, кроме `B`, берём полный граф, удаляем ребро `AC`, добавляем единственное ребро `BC`. Тогда `B` лист, расстояние от `A` до `B` равно 3, а после первого хода Васи Петя разрушает `BC` и изолирует `B`.

Внешние теоремы: не используются. Решение опирается только на определение расстояния в графе и подсчёт максимального числа рёбер при запрете общего соседа у двух выделенных вершин.
