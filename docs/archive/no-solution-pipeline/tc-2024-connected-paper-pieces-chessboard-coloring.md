# tc-2024-connected-paper-pieces-chessboard-coloring

## Краткий итог

Карточка была без решения и с неполной формулировкой. Официальный источник найден: 45-й Турнир городов, устный тур 2023/24, 11 класс, задача 6. Автор задачи: Т. В. Казицына. Официальный ответ: 45 кусков.

В карточку добавлено ИИ-решение по первой официальной идее: потенциалом служит число пар соседних готовых диагоналей. После первого куска этот потенциал равен 0, в конце равен 88, а один новый связный одноцветный кусок может увеличить его не более чем на 2. Конструкция из 45 вложенных ромбов вокруг центральной клетки даёт верхнюю оценку.

## Внешние теоремы

Внешние теоремы не использованы. Доказательство полностью школьное: нужны только связность клеточного куска, диагонали клетчатой доски, шахматная раскраска и монотонный потенциал.

Отдельную карточку-теорему добавлять не стоит. Если выносить что-то как стандартную идею, то скорее маленькую лемму: связное множество клеток пересекает подряд идущие диагонали одного направления.
