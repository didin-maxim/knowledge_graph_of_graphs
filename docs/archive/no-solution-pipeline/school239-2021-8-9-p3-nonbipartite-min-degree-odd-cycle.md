## Итог по решению

Решение добавлено в карточку как `sol-ai-shortest-cycle-and-blow-up`; в заголовке решения и в `editorial.notes` стоит пометка `ИИ-решение`.

Ответ: `k = 159`.

Идея верхней оценки: если кратчайший нечётный цикл имеет длину `g >= 5`, то у него нет хорд, а внешняя вершина не может быть смежна с тремя его вершинами. Из минимальной степени 3 каждая вершина цикла даёт хотя бы одно ребро наружу, каждую внешнюю вершину считаем не более двух раз, поэтому `239 >= g + ceil(g/2) = (3g+1)/2`, значит `g <= 159`.

Идея точности: взять цикл `C_159`, выбрать 79 вершин, попарно не лежащих на расстоянии 2 по циклу, заменить их одноэлементными долями, остальные 80 вершин — двухэлементными долями, а между соседними долями провести полные двудольные связи. Получается 239 вершин, минимальная степень не меньше 3, и проекция любого цикла на `C_159` показывает, что нечётных циклов короче 159 нет.
