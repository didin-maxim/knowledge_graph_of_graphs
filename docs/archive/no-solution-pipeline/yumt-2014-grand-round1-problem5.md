## Почему не добавлено решение

Идея из карточки про остовный лес и фундаментальные циклы сама по себе не закрывает задачу: дополнительных рёбер порядка `2n`, а возможных длин циклов до `3n-2`, поэтому прямой принцип Дирихле не срабатывает.

RMM 2019 действительно является более сильным утверждением по духу: для любого `epsilon > 0` достаточно большой граф с `(1+epsilon)N` рёбрами имеет два цикла одинаковой длины. Но это асимптотическое утверждение, а задача ЮМТ требует точного результата для всех `n` в специальной плотности `N=3n`, `E=5n`. Перенос требует либо явных констант и проверки малых случаев, либо отдельной самодостаточной сильной леммы. Быстро получить такой школьный текст без риска разрыва доказательства не удалось.

## Внешняя теорема

Потенциальная теорема для отдельной карточки: асимптотическая теорема RMM 2019 / Erdős-type result о графах с более чем `(1+epsilon)N` рёбрами и двумя циклами равной длины; эквивалентно, графы без повторяющихся длин циклов имеют только `N+o(N)` рёбер.

Оценка школьности: сама RMM-формулировка олимпиадная, но доказательство использует нетривиальную экстремальную идею с обхватом, excess-функцией и рекурсивным удалением длинных цепей степени 2. Для базы её лучше добавлять отдельной карточкой-теоремой или леммой, а не прятать как "очевидный" шаг в решении ЮМТ.
