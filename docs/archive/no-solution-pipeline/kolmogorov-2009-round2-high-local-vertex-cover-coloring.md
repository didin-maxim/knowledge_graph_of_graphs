Решение в карточку не добавлено. Официальный архив `src-kolmogorov-2009-official` был скачан с `https://turmath.ru/kolm/files/archive/kolm13.zip`; файл `tur2_13.doc` содержит эту задачу как Второй тур 2.12.09, Первая лига, задача 6. В официальном тексте нет явного условия `|V(G)| >= 2d+2`.

## Математическая заметка

Если вручную подтвердится, что в задаче подразумевалось `|V(G)| >= 2d+2`, то исправленный вариант, вероятно, имеет короткое доказательство через критические графы:

- если `χ(G) >= d+3`, берём `(d+3)`-критический подграф `H`;
- у него минимальная степень не меньше `d+2`;
- если `|H| < 2d+2`, то любое вершинное покрытие `H` имеет размер хотя бы `d+2`, и `H` можно расширить до запрещённого множества из `2d+2` вершин;
- если `|H| >= 2d+2`, нужна лемма Дирака о длинном цикле в 2-связном графе минимальной степени `δ`: есть цикл длины хотя бы `min(n, 2δ)`, после чего `2d+2` последовательных вершин цикла уже требуют вершинного покрытия размера `d+1`.

Лемма Дирака о длинном цикле имеет школьное доказательство через максимальный путь/цикл, но как отдельный шаг она достаточно нетривиальна. Если исправленный вариант будет принят, стоит либо доказать эту лемму прямо в решении, либо добавить отдельную карточку-лемму про длинный цикл в 2-связном графе.
