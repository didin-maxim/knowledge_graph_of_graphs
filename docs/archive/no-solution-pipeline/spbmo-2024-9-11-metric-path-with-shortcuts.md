## Почему решение не добавлено

Быстрый самостоятельный проход дал устойчивую редукцию, но не закрыл точную экстремальную оценку.

- Достаточно рассматривать остовное дерево: его рёбра можно разбивать на линии, а остальные рёбра исходного графа класть в однотоннельные линии и не использовать в маршрутах.
- Для дерева задача превращается в разбиение рёбер на простые пути так, чтобы граф пересадок между путями имел малый диаметр.
- Естественные подходы через тяжёлые пути или рекурсивный путь-сепаратор дают правдоподобные логарифмические оценки, но для карточки нужен точный максимум `N`, включая строгий контрпример для `N+1`.
- Поэтому в карточку добавлена аккуратная пометка `непросто для ИИ`, а `solutions[]` оставлен пустым.

## Внешние теоремы

В карточку не добавлено решение, поэтому внешние теоремы не используются.

Для будущего решения может понадобиться лемма о разбиении дерева на пути с малым диаметром графа пересадок. Если она формулируется как самостоятельный путь-сепаратор/тяжёлое разбиение с точной экстремальной оценкой, её стоит добавить отдельной карточкой: доказательство базовой верхней оценки через heavy-light decomposition школьное, но точная нижняя оценка для экстремального `N` выглядит менее стандартной и требует аккуратной отдельной упаковки.
