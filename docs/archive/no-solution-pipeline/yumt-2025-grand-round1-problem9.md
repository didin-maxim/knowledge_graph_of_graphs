# yumt-2025-grand-round1-problem9

## Краткий итог

Карточка была без решения. Точный публичный разбор, автор или отдельный источник с этой конкретной задачей по поисковым запросам не найдены.

Добавлено ИИ-решение. Ответ: `38`.

Суть решения: допустимые разбиения для трёх цветов кодируют каждую вершину тройкой номеров групп. Две вершины не могут иметь одинаковую тройку, иначе ребро между ними имело бы цвет `r_i`, но его концы лежали бы в одной группе для этого цвета. Поэтому `2025 <= a1*a2*a3`. При сумме не больше `37` максимальное произведение равно `12*12*13 = 1872`, значит сумма не меньше `38`. Достижимость даёт выбор `2025` точек из сетки `12 x 13 x 13` и окраска ребра в первый цвет, по координате которого концы различаются.
