# kolmogorov-2009-round2-high-local-vertex-cover-coloring: very-high pass

## Итог

Решение в карточку не добавлено: `solutions: []` оставлен без изменений. Главная причина не только сложность и отсутствие опубликованного решения, а сомнительная буквальная формулировка: в официальном тексте нет явного условия `|V(G)| >= 2d+2`, поэтому `editorial.public_ready` должен оставаться `false`.

Буквальная формулировка ложна для графов с меньшим числом вершин. При `d = 2` граф `K5` не содержит 6-элементных множеств вершин, значит локальное условие выполняется вакуозно, но `K5` не раскрашивается в `d+2 = 4` цвета.

## Проверка источников

- Официальный архив `src-kolmogorov-archive`: `https://turmath.ru/kolm/archive.php`.
- Официальный архив 2009 года `src-kolmogorov-2009-official`: `https://www.turmath.ru/kolm/files/archive/kolm13.zip`. Через `curl` архив корректно скачан и распакован; внутри есть `tur2_13.doc`, но нет очевидного файла с решениями этой задачи.
- Зеркало GUAS с TeX-исходниками: `https://www.guas.info/competit/kolm/kolm13/tur2.tex`. Файл в кодировке CP866 подтверждает: Второй тур 2.12.09, Первая лига, задача 6; заключение именно в `d+2` цвета; авторы указаны как `В. Дольников, И. Богданов, упрощение`.
- В том же TeX-файле есть родственная версия для Высшей юниорской лиги: та же локальная гипотеза, но заключение в `d+1` цвет; авторы `В. Дольников, И. Богданов, Д. Фон-дер-Флаасс`. Это не текущая карточка, но важно для ручной сверки семейства задач.

Проверенные веб-запросы включали точные фразы `"В каждом множестве из 2d+2 вершин графа"`, `"Среди любых 2d+2 вершин графа"`, `"вершины графа можно раскрасить в d+2 цвета"`, `"В. Дольников" "И. Богданов" "2d+2"`, а также английские переформулировки про `every set of 2d+2 vertices`, `vertex cover`, `independent set`, `k-colorable`. Полного опубликованного решения, форумного разбора или авторского комментария не найдено; найденные совпадения были либо нерелевантными, либо общими материалами по раскраскам/критическим графам.

- Убрал из базы недоведённую доказательную трассу: `problem_profile.methods` очищен, а теги `minimal_counterexample` и `degree_counting` удалены из карточки.

- Проверил `source_id`: `src-kolmogorov-2009-official` и `src-kolmogorov-archive` существуют в `data/sources/sources.yaml` и подходят; общий файл источников не редактировался.
