# yumt-2023-granda-final-problem6

## Краткий итог

Карточка была без решения. Публичное/официальное решение именно этой задачи ЮМТ 2023, Гранд-лига A, финал, задача 6, по точной формулировке не найдено.

Полное ИИ-решение за быстрый проход не получено. Добавлена пометка: **непросто для ИИ**.

Есть простой частный случай: если \(G\) содержит клику \(K_n\), то берём её за \(G_1\), а любую вершину вне этой клики за \(G_2\). Тогда \(\chi(G_1)+\chi(G_2)=n+1\).

Трудный остаток: \(\omega(G)<\chi(G)=n\). Этот случай напрямую соседствует с темой Erdős-Lovász-Tihany: для графов с \(\omega(G)<\chi(G)=s+t-1\) ожидаются два непересекающихся подграфа хроматических чисел \(s\) и \(t\). Поэтому без официального разбора нельзя безопасно подставлять сильную внешнюю теорему как школьное решение.

- Поиск по точным фразам русской формулировки, `ЮМТ 2023`, `Гранд-лига A`, `финал`, `задача 6`, `χ(G1)+χ(G2)` не дал опубликованного решения или имени автора.

## Внешние теоремы

Теорема/гипотеза Erdős-Lovász-Tihany в форме из arXiv:1309.1020: для \(s,t\ge 2\), \(s+t-1=\chi(G)>\omega(G)\), ожидается разбиение \(V(G)=S\sqcup T\) с \(\chi(G[S])\ge s\), \(\chi(G[T])\ge t\). В аннотации источника явно указано, что для общих графов известны только отдельные малые случаи и специальные классы.

Оценка школьности: как готовый чёрный ящик эта теория слишком сильна для олимпиадной карточки и, в общей форме, является не закрытой теоремой. Её нельзя использовать как полноценное решение задачи без дополнительной проверки, что формулировка ЮМТ является существенно более слабым доказанным следствием или что есть официальный элементарный обход.
