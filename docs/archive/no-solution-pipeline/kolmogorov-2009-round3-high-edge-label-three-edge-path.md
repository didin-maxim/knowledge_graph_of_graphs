## Самостоятельная попытка

Быстрый подход через первые `m` рёбер даёт только начальную редукцию. Если среди первых `m` рёбер есть путь/замкнутый путь из трёх рёбер и `m <= n-333`, то сумма трёх его меток не больше `m+(m-1)+(m-2) <= 3n-1002`, и задача решена.

Значит, в контрпримерном рассуждении граф из первых примерно `n` рёбер должен долго оставаться близким к экстремальным графам без трёхрёберного пути. Такие графы являются лесами звёзд, но дальше нужно контролировать не только появление нового трёхрёберного пути, а сумму меток в нём. Именно этот взвешенный шаг оказался нетривиальным: новая малая метка может соединять "плохие" вершины звёзд, и простой подсчёт компонентов/плохих вершин не даёт константу `1000`.

Надёжного ИИ-решения за проход не получено. В карточке оставлена пометка "непросто для ИИ"; полноценное решение не добавлялось.
