## Найденная идея

Индукционный маршрут такой. Если есть вершина степени 0 или 1, её удаление сохраняет требуемую оценку. Если есть вершина степени 2, то после удаления по индукции получается

```text
m(G) <= (2(n-1)-1) + 2 = 2n - 1.
```

Значит, достаточно доказать лемму: в любом простом графе без циклов длины 3 и 4, в котором любые два цикла пересекаются по вершинам, есть вершина степени не больше 2. Эквивалентная более сильная формулировка: граф минимальной степени хотя бы 3 и обхвата хотя бы 5 содержит два непересекающихся по вершинам цикла.

Эта лемма выглядит правдоподобной и согласуется с известной классификацией графов без двух непересекающихся циклов, но сама такая классификация не является школьной внешней теоремой. Поэтому отдельную карточку/связь на неё сейчас не добавлял.

## Внешние теоремы

В карточном решении внешние теоремы не использованы, потому что решения нет.

Потенциально релевантная внешняя теорема: классификация Ловаса графов без двух непересекающихся циклов при минимальной степени хотя бы 3. Это не школьный результат; если использовать его как prerequisite, нужна отдельная карточка-теорема или явная пометка, что доказательство вынесено наружу. Для юниорской задачи такой путь выглядит слишком тяжёлым.
