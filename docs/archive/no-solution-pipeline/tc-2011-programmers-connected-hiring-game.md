# tc-2011-programmers-connected-hiring-game

## Что найдено

Карточка была без решения и с усечённым условием. Внешний поиск нашёл официальную задачу А. В. Шаповалова из 32-го Международного математического Турнира городов, 2010/11, весенний тур, сложный вариант, 10-11 классы, задача 7: 11 гениев, нужно построить знакомства, при которых вторая фирма гарантирует 10 гениев.

Использованные источники:

- Официальный источник уже есть в базе: `src-tc-2011-32-vs32sl-official`, URL `https://www.turgor.ru/problems/32/vs32sl-avt.pdf`.
- Дополнительная сверка: problems.ru, задача 116286, `https://problems.ru/view_problem_details_new.php?id=116286`.
- Дополнительная сверка и перепечатка решения: «Квант», 2012, №1, задача М2235, `https://kvant.mccme.ru/pdf/2012/2012-01.pdf`.

## Что сделано

В карточке восстановлены автор, точная формулировка и графовая постановка. Добавлено полноценное ИИ-решение со ссылкой на существующий официальный `source_id`: конструкция на векторах из 11 неотрицательных целых координат с суммой 100, где соседство означает перенос единицы между координатами, а гении - вершины симплекса.

Ключевой инвариант решения: после первого ответа второй фирмы поддерживаются строгие неравенства `M_i > m_i` для десяти координат, где `M_i` и `m_i` - максимальные значения координаты среди нанятых второй и первой фирмой. Если первая фирма догоняет по одной координате, вторая делает соседний ход, увеличивающий соответствующий максимум; если не догоняет, вторая сама продвигает любой ещё не доведённый до 100 максимум. Достижение `M_i = 100` означает найм соответствующего гения.

Внешних теорем не использовано. Доказательство полностью школьное: нужны только графовая интерпретация игры, работа с целыми координатами и инвариант. Отдельную карточку-теорему добавлять не нужно; максимум можно когда-нибудь завести стандартную идею «координатный потенциал в позиционной игре», но это не теорема.
