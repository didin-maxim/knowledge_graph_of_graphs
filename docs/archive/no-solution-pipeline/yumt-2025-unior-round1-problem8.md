## Итог по решению

Решение добавлено в карточку как `sol-ai-order-on-disjoint-quadratics` с явной пометкой `ИИ-решение`.

Ответ: только `n = 2`.

Идея: если графики двух квадратных трёхчленов не пересекаются, то один трёхчлен всюду выше другого. Для `n >= 3` чётные вершины цикла дают цепь из `n` попарно непересекающихся трёхчленов. Каждый нечётный трёхчлен должен быть несравним ровно с двумя соседними чётными; в цепи эти два чётных трёхчлена обязаны стоять рядом. Так все `n` циклических пар чётных вершин должны стать соседними парами в одном линейном порядке, но у линейного порядка из `n` элементов только `n-1` соседних пар. Противоречие.

Для `n = 2` конструкция по циклу `C_4`: `x^2`, `-x^2+2`, `x^2+1`, `-x^2+3`.
