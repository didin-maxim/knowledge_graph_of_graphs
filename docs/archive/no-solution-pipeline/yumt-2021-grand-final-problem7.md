## Идея решения

Ключевая лемма: в графе без `K_4`, где любые два треугольника имеют общую вершину, есть независимое множество `S`, пересекающее каждый треугольник.

Если все треугольники имеют общую вершину, берём её. Иначе находятся два треугольника `xab` и `xcd`, пересекающиеся только в `x`. Любой треугольник без `x` обязан иметь вид `pqy`, где `p` из `{a,b}`, `q` из `{c,d}`, а `y` лежит вне этих пяти вершин; иначе возник бы `K_4`. Все такие вершины `y` не смежны с `x` и попарно не смежны: при наличии ребра между двумя хвостами либо появился бы треугольник, не пересекающий один из базовых треугольников, либо две исходные тройки оказались бы непересекающимися. Поэтому `{x}` вместе со всеми такими `y` — независимое множество, бьющее все треугольники.

После удаления `S` индуцированный подграф не содержит треугольников и по условию красится в `k` цветов. Множество `S` красится новым цветом, значит, весь граф красится в `k+1` цвет.
