# yumt-2024-grand-round3-problem8

## Краткий итог

Карточка была без решения. Готовый публичный разбор, автор и внешний источник с решением по точной формулировке и идентификатору `yumt-2024-grand-round3-problem8` в интернете не найдены.

Добавлено ИИ-решение: достаточно использовать инвариант числа рёбер после удаления двух вершин. Если удаляются `u` и `v`, число удалённых рёбер равно `d(u)+d(v)-eps(u,v)`, значит эта величина постоянна для всех пар. Сравнение вершин минимальной и максимальной степени исключает нерегулярный случай при `n >= 4`; регулярный граф не может одновременно иметь ребро и неребро.

## Найденные источники

- Интернет-поиск по точной русской формулировке, по фразам `Петя стирает две вершины`, `один и тот же граф после удаления двух вершин`, а также по идентификаторам ЮМТ не дал публичного решения или автора.

## Внешние теоремы

Внешние теоремы не использованы. Решение полностью элементарное: подсчёт рёбер после удаления пары вершин и сравнение степеней.
