## Поиск Источников

Проверялись точные фразы из условия: `"В стране 20 городов" "четырём компаниям"`, `"антимонопольному закону" "авиакомпания"`, а также варианты по `yumt 2012 start round3 problem1` и поиски по `adygmath.ru` для решений 2012 года. Разбор именно этой задачи не найден.

Подтверждён теоретический фон:

- OEIS A343607: https://oeis.org/A343607. Последовательность описывает минимальное число цветов для раскраски рёбер `K_n` без одноцветного треугольника; для `n=20` значение равно 4.
- Small Ramsey Numbers, Dynamic Survey DS1: https://www.combinatorics.org/ojs/index.php/eljc/article/view/DS1. Обзор фиксирует контекст малых чисел Рамсея и многокрасочных раскрасок без монохроматических полных подграфов.

## Математика

Условие эквивалентно вопросу, можно ли раскрасить рёбра `K_20` в 4 цвета без одноцветного треугольника. Ответ положительный.

Конструкция школьная: разбить города на 5 групп по 4. Между группами две компании работают по `C_5` и дополнению к `C_5`; внутри каждой четвёрки третья компания получает цикл длины 4, а четвёртая -- две диагонали. Проверка сводится к тому, что ни `C_5`, ни его дополнение, ни `C_4`, ни паросочетание из двух диагоналей не содержат треугольников.

Внешняя теорема не нужна. Теорему Рамсея или точное значение `R(3,3,3,3)` в решение добавлять не стоит: они существенно сильнее задачи. Отдельную карточку можно завести только для маленькой стандартной идеи "двухцветная раскраска `K_5` как пятицикл и его дополнение без одноцветного треугольника", но для текущего решения это доказывается в одну строку и отдельная карточка не обязательна.
