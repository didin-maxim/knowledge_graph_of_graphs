## Итог по решению

Решение добавлено в карточку как `sol-ai-distance-three-extremal` с явной пометкой `ИИ-решение`.

Ответ: `C(n-1,2)`.

Идея решения короткая. Если после выбора `A,B` расстояние между ними в исходном графе не больше 2, Вася выигрывает первым ходом. Поэтому для выигрыша Пети нужна пара на расстоянии хотя бы 3. Тогда отсутствует ребро `AB`, а для каждой другой вершины отсутствует хотя бы одно из ребер к `A` и `B`; всего недостающих ребер не меньше `n-1`, значит `k <= C(n,2)-(n-1)=C(n-1,2)`. Равенство достигается графом `K_{n-1}` без ребра `Ax` плюс лист `B`, соединенный только с `x`; после первого хода Васи Петя удаляет ребро `xB`.

## Внешние теоремы

Внешних тяжелых теорем не использовано. Нужны только элементарные факты о расстоянии в графе, полном графе и подсчете недостающих ребер. Отдельную стандартную идею добавлять не обязательно.
