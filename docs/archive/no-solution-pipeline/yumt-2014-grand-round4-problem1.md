## Содержание решения

Ключевая верхняя оценка берёт пару городов `a,b`, между которыми нет пути длины 1 или 2. Для каждого из остальных 98 городов выбирается одна отсутствующая пара из `av`, `bv`; выбранная пара должна соединяться внутри какой-то авиакомпании. Если у компании `m` рейсов, то она может отвечать не более чем за `m-1` таких городов. Поэтому `sum(m_i - 1) = 2014 - n >= 98`, откуда `n <= 1916`.

Конструкция: одна компания получает остовный путь на всех 100 городах, остальные `1915` рейсов добавляются внутри 98 внутренних вершин пути и выдаются отдельным компаниям. Концы пути остаются без общего соседа, а первая компания соединяет любую пару городов.
