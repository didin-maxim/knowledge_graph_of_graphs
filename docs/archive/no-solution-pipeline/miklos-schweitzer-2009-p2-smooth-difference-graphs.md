# Miklos Schweitzer 2009 P2: smooth difference graphs

## Итог

Карточка была без решения. Найден внешний разбор на странице KöMaL A.494 и добавлено самодостаточное ИИ-решение в `solutions[]`.

Ответы:

- (i) Нет: если взять простое `q`, не входящее в список разрешённых простых, то среди `q+1` элементов два сравнимы по модулю `q`; их разность имеет запрещённый простой делитель.
- (ii) Да: для `P=p_1...p_k` множество `A={a_1,...,a_m}`, где `a_n=P+P^2+...+P^n`, даёт ровно путь, потому что соседние разности равны степеням `P`, а несоседние разности содержат дополнительный простой делитель.
