## Идея решения

Ответ: `100`.

Нижняя оценка даётся циклом `C_100`: удаление любых двух непересекающихся рёбер разбивает цикл на две цепи.

Для верхней оценки достаточно доказать, что граф не может иметь две независимые циклические части и не может иметь одну циклическую часть сложнее простого цикла. В первом случае выбираем по одному ребру в двух разных частях без мостов; удаление одного ребра из такой части не нарушает её связности, и весь граф остаётся связным. Во втором случае внутри части без мостов, не являющейся циклом, есть theta-подграф; в двух его цепях выбираются непересекающиеся рёбра так, что третья цепь сохраняет связность. Оба случая противоречат условию.

Значит граф является деревом или унициклическим графом, поэтому при 100 вершинах имеет не больше `99 + 1 = 100` рёбер.
