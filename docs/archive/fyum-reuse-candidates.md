# FYUM reuse candidates without accessible official solutions

This note collects FYUM year-level source pools whose original statements were found but official solutions were not available in the checked archive. These pools are useful for later extraction of simpler graph tasks that could be recycled for lower-level math battles.

The explicit graph task `fyum-2012-tur1a-p10` is no longer in this backlog: it has now been imported into the database using the official FYUM statement plus a standard theorem-level solution transfer for strong edge-coloring.

## Use policy

- Treat these entries as source pools, not as already-curated individual cards.
- Reuse only after extracting a clean statement and checking whether a verified solution exists or can be transferred from a standard theorem/generalization.
- Prefer problems whose graph content is explicit in the statement, or whose graph reformulation is short and self-contained.
