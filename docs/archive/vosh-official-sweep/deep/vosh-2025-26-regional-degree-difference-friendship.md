## Вывод

Официальные материалы подтверждают карточку: это региональный этап ВсОШ 2025/26, математика, 10 класс, второй день, задача 10.8. Ответ: `1013 * 1012`.

Индивидуальный автор/proposer в просмотренном PDF не указан. На титульных/вводных страницах сказано, что задания подготовлены Центральной предметно-методической комиссией по математике Всероссийской олимпиады школьников; карточка не выводит из этого персонального автора.

Графовая модель корректна:

- математики становятся вершинами простого неориентированного графа;
- пары друзей становятся рёбрами;
- число друзей математика становится степенью соответствующей вершины;
- условие превращается в требование `|deg u - deg v| = 1` для каждого ребра `uv`;
- нужно максимизировать число рёбер.

Официальное решение совпадает с карточкой по структуре:

- положено `k = 1013`, всего вершин `2k`;
- нижняя оценка достигается графом `K_{k,k-1}` плюс одна изолированная вершина;
- для оценки сверху вершины разбиваются на слои `X_i` по степени;
- каждое ребро идёт только между соседними слоями `X_{i-1}` и `X_i`;
- при максимальной степени `m <= k-1` работает лемма о сумме степеней;
- случай `m >= k+1` невозможен, потому что слои `X_{m-1}`, `X_m`, `X_{m-2}` дали бы больше `2k` вершин;
- при `m = k` слои делятся на две паритетные части `Y` и `Z`, и подсчёт рёбер по концам в этих частях даёт `|E| <= k(k-1)`.
