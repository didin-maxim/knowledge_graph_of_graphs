# Miklos Schweitzer 2000-2008 graph audit

## Добавлено

- `data/problems/miklos-schweitzer/miklos-schweitzer-2002-p2-edge-connected-short-paths.yaml`
  - PDF: https://www.math.u-szeged.hu/tagok/mmaroti/schweitzer/schweitzer-2002-eng.pdf
  - Задача 2: простой k-реберно-связный граф и k коротких реберно-непересекающихся путей.
  - Язык источника: английский.
  - Решение в PDF не опубликовано; карточка `needs_human_review`.
- `data/problems/miklos-schweitzer/miklos-schweitzer-2004-p2-quasirandom-k4-count.yaml`
  - PDF: https://www.math.u-szeged.hu/tagok/mmaroti/schweitzer/schweitzer-2004-eng.pdf
  - Задача 2: два простых графа на общем множестве вершин, близость всех индуцированных чисел ребер, оценка числа полных четырехвершинников.
  - Язык источника: английский.
  - Термин `complete quadrilateral` интерпретирован как копия K4; нужна ручная сверка.
- `data/problems/miklos-schweitzer/miklos-schweitzer-2004-p3-planar-embedding-edge-ratio.yaml`
  - PDF: https://www.math.u-szeged.hu/tagok/mmaroti/schweitzer/schweitzer-2004-eng.pdf
  - Задача 3: планарный граф, в каждом прямолинейном плоском вложении есть пара ребер с отношением длин хотя бы cn.
  - Язык источника: английский.
  - Решение в PDF не опубликовано; карточка `needs_human_review`.
- `data/problems/miklos-schweitzer/miklos-schweitzer-2005-p1-high-chromatic-defined-graph.yaml`
  - PDF: https://www.math.u-szeged.hu/tagok/mmaroti/schweitzer/schweitzer-2005.pdf
  - Задача 1: явно заданный неориентированный граф G(a,b), доказать неограниченность хроматического числа.
  - Язык источника: венгерский; карточка помечена `needs_human_review`.
- `data/problems/miklos-schweitzer/miklos-schweitzer-2008-p3-tame-bipartite-graphs.yaml`
  - PDF: https://www.math.u-szeged.hu/tagok/mmaroti/schweitzer/schweitzer-2008-eng.pdf
  - Задача 3: двудольные ordered/tame graphs с запрещенным путем x_i y_j x_k y_l и экстремальным числом ребер.
  - Язык источника: английский.
  - Решение в PDF не опубликовано; карточка `needs_human_review`.

- 2007 English PDF: https://www.math.u-szeged.hu/tagok/mmaroti/schweitzer/schweitzer-2007-eng.pdf

## Замечания

- Для 2002, 2004, 2008 в индексе доступны английские PDF, но не опубликованные решения; поэтому решения не добавлены, кроме кратких идей.
- Для 2005 доступен только венгерский PDF; карточка создана на русском и помечена `needs_human_review`.
- Реестр `data/sources` не редактировался; `source_id` указан локально внутри карточек в формате `src-miklos-schweitzer-YYYY-pN-official`.
